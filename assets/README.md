# Brand assets

| File | What it is |
|---|---|
| `paperl10n-mark.svg` | The Paper Lion mark: a lion whose mane is a sheet of paper with a folded corner. 512×512 viewBox, with an accessible `<title>`. |
| `icons/paperl10n-<size>.png` | The app icon: the mark, unmodified, rendered at 16–512 px with a clear background. Generated by `pnpm render:icons` (`scripts/render-app-icons.ts`, with the project's own Electron); rerun it when the mark changes. Same license as the mark. |

Palette used in the mark (a starting point for the design tokens, see `docs/plan/UI-UX.md`):

| Role in the mark | Color |
|---|---|
| Ink (outlines, eyes, nose) | `#14213D` |
| Mane (paper) | `#FDF6E7` |
| Folded corner | `#F7E6C4` |
| Head and ears | `#F9B233` |
| Inner ears | `#D9891C` |
| Muzzle | `#FDEBD2` |

The UI imports the mark through `#assets/…`. The Electron main process sets the 512 px icon on
the window (and the macOS dock) at run time. Installer formats (`.ico`, `.icns`) come with
packaging, and a simplified mark for 16–32 px may come later.
