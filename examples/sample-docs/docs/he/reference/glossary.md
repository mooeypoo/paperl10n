# מילון מונחים

| מונח | משמעות |
|---|---|
| דף | קובץ Markdown אחד בתיקייה `docs/`, שמוגש בכתובת URL אחת. |
| שפה (Locale) | קוד שפה כמו `en` או `he`, עם כיוון כתיבה. |
| בסיס (Base) | הנתיב שתחתיו האתר נמצא, למשל `/docs/`. |
| Frontmatter | בלוק ה־YAML שבין שורות `---` בראש הדף. |

## מגבלות

- דף יכול להכיל עד 5 MB של Markdown.
- אתר יכול לכלול עד 10,000 דפים; אתרים גדולים יותר כדאי לפצל לכמה אתרים.
- ‏Lantern 2.1 דורש Node.js בגרסה 24 ומעלה.
