# הגדרות

‏Lantern עובד בלי שום הגדרות. כשרוצים לשנות משהו, יוצרים את הקובץ `lantern.config.json` ליד
התיקייה `docs/`.

## הגדרות מינימליות

```json
{
  "title": "האתר שלי",
  "logo": "/logo.svg",
  "locales": ["en", "he"]
}
```

## כל האפשרויות

| אפשרות | סוג | ברירת מחדל | משמעות |
|---|---|---|---|
| `title` | string | שם התיקייה | מוצגת בלשונית הדפדפן ובכותרת העליונה. |
| `logo` | string | אין | נתיב לתמונה בתיקייה `docs/public/`. |
| `locales` | string[] | `["en"]` | השפות של האתר. הראשונה היא ברירת המחדל. |
| `base` | string | `/` | הנתיב שממנו האתר מוגש, למשל `/docs/`. |
| `cleanUrls` | boolean | `true` | הגשת `/guide/setup` במקום `/guide/setup.html`. |

## שפות

לכל שפה יש תיקייה משלה תחת `docs/`: ‏`docs/en/`, ‏`docs/he/` וכן הלאה. ‏Lantern מגדיר בשבילכם את
המאפיינים `lang` ו־`dir` של הדף, כך ששפות מימין לשמאל מוצגות נכון.
