# מתחילים

המדריך הזה לוקח אתכם מתיקייה ריקה לאתר שרץ. צריך [Node.js](https://nodejs.org/) בגרסה 24 ומעלה.

## התקנת Lantern

צרו תיקייה לאתר והתקינו בה את Lantern:

```sh
mkdir my-site && cd my-site
npm install --save-dev lantern
```

<Badge type="tip" text="חדש בגרסה 2.0" /> עכשיו Lantern יוצר בשבילכם תיקיית `docs/` התחלתית.

## יצירת הדף הראשון

‏Lantern קורא דפים מהתיקייה `docs/`. צרו את הקובץ `docs/index.md`:

```md
# שלום

זה הדף הראשון שלי ב־Lantern.
```

## הפעלת שרת הפיתוח

הריצו `npx lantern dev` ופתחו את <http://localhost:4173>. הדף נטען מחדש בכל פעם ששומרים קובץ.

## הצעדים הבאים

1. הוסיפו עוד דפים לתיקייה `docs/`. כל קובץ הופך לדף.
2. הגדירו כותרת ולוגו ב[הגדרות](./configuration.md).
3. כשתהיו מוכנים, הריצו `npx lantern build` והעלו את התיקייה `dist/` לכל מקום שתרצו.

::: tip
נתקעתם? ב[מדריך שורת הפקודה](../reference/cli.md) תמצאו כל פקודה ודגל.
:::
