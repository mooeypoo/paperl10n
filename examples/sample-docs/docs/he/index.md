# Lantern

‏Lantern הופך תיקייה של קובצי Markdown לאתר מהיר ונגיש. אין מסד נתונים ואין שרת לתחזק: רק קבצים
שאפשר לקרוא, לבדוק ולנהל בגרסאות.

## למה Lantern?

- **קבצים פשוטים.** כל דף הוא קובץ Markdown במאגר שלכם.
- **מהיר כברירת מחדל.** הדפים נבנים מראש ושוקלים פחות מ־50 KB.
- **כל שפה.** כתבים מימין לשמאל, כמו עברית וערבית, עובדים מהרגע הראשון.

## מאיפה מתחילים

קראו את [המדריך להתחלה](./guide/getting-started.md) כדי לבנות את האתר הראשון שלכם בחמש דקות, ואז
עברו ל[הגדרות](./guide/configuration.md) כדי לראות כל מה שאפשר לשנות.
