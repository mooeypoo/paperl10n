# Lantern

Lantern turns a folder of Markdown files into a fast, accessible website. There's no database
and no server to maintain: just files you can read, review, and version.

## Why Lantern?

- **Plain files.** Every page is a Markdown file in your repository.
- **Fast by default.** Pages are built ahead of time and weigh less than 50 KB.
- **Every language.** Right-to-left scripts like Hebrew and Arabic work out of the box.

## Where to start

Read [Getting started](./guide/getting-started.md) to build your first site in five minutes, then
see [Configuration](./guide/configuration.md) for everything you can change.
