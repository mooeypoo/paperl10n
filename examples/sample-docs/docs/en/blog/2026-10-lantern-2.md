# Lantern 2.0 is here

Lantern 2.0 is the biggest release yet. The headline: **every language is a first-class
language**, including right-to-left ones.

## What's new

- Per-locale folders, with `lang` and `dir` set on every page.
- Offline search in every language.
- `lantern check`, which finds broken links before your readers do.

## Upgrading

Most sites upgrade without changes. If you used the old `i18n` option, rename it to `locales`.
