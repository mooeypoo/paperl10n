# Glossary

| Term | Meaning |
|---|---|
| Page | One Markdown file in `docs/`, served as one URL. |
| Locale | A language code such as `en` or `he`, with a text direction. |
| Base | The path your site lives under, such as `/docs/`. |
| Frontmatter | The YAML block between `---` lines at the top of a page. |

## Limits

- A page can be up to 5 MB of Markdown.
- A site can have up to 10,000 pages; larger sites should split into several.
- Lantern 2.1 needs Node.js 24 or later.
